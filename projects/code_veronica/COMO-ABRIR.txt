ABRIR CODE VERONICA

De dois cliques em "Abrir Code Veronica" (atalho) ou em
"executar-code-veronica-otimizado.cmd". Os dois abrem a versao otimizada
(build-release\bin\MyGameRecomp.exe) com a pasta do jogo ja configurada.
Nao abra o MyGameRecomp.exe direto: sem o iniciador ele nao acha o jogo.
Feche a janela do jogo para encerrar. O terminal permanece aberto para mostrar erros.
O log fica em run-log-release.txt, nesta pasta.

Para recompilar depois de mudar o codigo: de dois cliques em build-release.cmd.

CONTROLES PELO TECLADO (quando nao houver controle XInput conectado)
Setas = direcao; X = confirmar (Cruz); Z = Circulo; A = Quadrado; S = Triangulo.
I = Start; R = Select. Enter e Tab continuam como atalhos para Start e Select.

O executavel procura automaticamente EBOOT.elf em D:\ps3recomp\JOGO\NPEB00553.
