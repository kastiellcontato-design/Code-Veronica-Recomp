# Veronica Port v1.0

## Português

Escolha o download em **Assets**:

- **CodeVeronica-PC-v1.0.zip** — port para Windows com launcher, três regiões,
  abertura pelo EXE sem CMD e instruções em português e inglês.
- **Veronica-PKG-Extractor-v1.0.zip** — ferramenta opcional para extrair seu PKG
  de Code Veronica para a pasta que o launcher usa. Selecione ou arraste o PKG,
  escolha o destino e clique em Extrair PKG.

Você pode preparar o jogo com **Veronica PKG Extractor ou RPCS3**. Use apenas um
dos métodos. Se já tem o jogo em pasta, não precisa baixar o extrator.
O launcher recebe a pasta com PARAM.SFO e USRDIR/EBOOT.BIN; não abre PKGs.
Somente versões PSN base 01.00: NPEB00553, NPUB30467 e NPJB00135.
EU/US precisam da sua licença RAP; JP não precisa. Nenhum jogo ou licença está
incluído. Extraia os ZIPs antes de abrir os executáveis.

## English

Choose your download under **Assets**:

- **CodeVeronica-PC-v1.0.zip** — Windows port with launcher, all three regions,
  direct EXE startup without a console, and Portuguese/English instructions.
- **Veronica-PKG-Extractor-v1.0.zip** — optional tool to extract your Code Veronica
  PKG into the folder required by the launcher. Drop or select the PKG, choose
  a destination and click Extract PKG.

Prepare your game with **Veronica PKG Extractor or RPCS3**. You only need one
method. If your game is already extracted, skip the extractor download.
The launcher accepts the folder containing PARAM.SFO and USRDIR/EBOOT.BIN,
not a PKG. Only PSN base version 01.00: NPEB00553, NPUB30467 and NPJB00135.
EU/US require your RAP license; JP does not. No game files or licenses are
included. Unzip each download before opening the executable.
