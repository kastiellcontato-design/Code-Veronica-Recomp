ATIVACAO PELO CATALOGO OFICIAL (RECOMENDADO)
O autosplitter do port ja foi incluido no catalogo oficial do LiveSplit.

1. Extraia este ZIP. No LiveSplit, use Open Splits > From File para abrir
   o .lss Any% ou S-Rank, se quiser uma lista de splits pronta com icones.
2. Abra Edit Splits. Em Game Name, cole EXATAMENTE:

   Resident Evil: Code: Veronica X (PS3 Recomp)

3. Clique Activate e depois Settings. Desative o autosplitter antigo de
   emuladores antes de trocar, se estiver ativo. Se nao aparecer, feche e
   abra o LiveSplit e digite o nome exato novamente; nao depende de sugestoes.
4. Marque Start e Split. Confira os eventos de acordo com sua rota e ative
   Load Remover Time se quiser descontar o tempo das portas.
5. No menu principal, selecione Compare Against > Game Time.
   O LRT pausa Game Time durante portas; Real Time continua contando.
6. Abra o port e salve seus splits e o layout no LiveSplit.

Nao precisa apontar para um ASL manualmente nesse metodo. Use so um
autosplitter: remova de Edit Layout um componente Scriptable Auto Splitter
adicionado manualmente antes de ativar a versao do catalogo.

O QUE ESTE ZIP OFERECE
Dois arquivos .lss prontos (Any% e S-Rank), com icones, suas marcacoes de
rota, licenca/creditos e guias. O nome do jogo ja foi ajustado para o
catalogo oficial. Nao ha arquivos ASL locais neste ZIP: o LiveSplit baixa
e carrega o script automaticamente ao clicar Activate.
Tempos e historico sao exemplos; limpe-os no LiveSplit para seu proprio uso.

O autosplitter do catalogo funciona no port PC EU/JP/US, nao nos emuladores.
Nao ative uma rota de todas as portas para splits somente por itens.
Catalogo oficial nao significa aprovacao em rankings; consulte os moderadores.
