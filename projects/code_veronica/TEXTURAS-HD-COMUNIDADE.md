## English

The textures are the work of other people in the Resident Evil community. The images were originally made for the PCSX2 (PS2) version of the game. For this port they were matched, image by image, to the PS3 textures and saved with the file names the port expects (see *Texture mods* in the README). The matching, the alpha-channel fixes and the packaging were done by **Kastiel** (port maintainer).

**Covers all three versions.** The game recognises a texture by its content, so one set of files serves every version:

| Version | Textures of the pack used |
|---|---|
| US (NPUB30467) | 5,926 (all) |
| EU (NPEB00553) | 5,908 (99.7%) |
| JP (NPJB00135) | 5,759 (97%) |

What a version does not use is ignored, and the game's own texture stays. The pack was built against the US version; on EU and JP only the existence of the texture names was checked, **not tested in play**.

**How to use**
1. Download and extract the zip.
2. Launcher → **Mods** → **Mod textures folder**: choose the `texturas` folder (the one that contains `comum`). Choose it **before** opening the game.
3. Turn on **Replace textures** and play. **F9** switches the pack on and off while playing.
4. Do not create a subfolder named after the version code (`NPUB30467`, `NPEB00553`, `NPJB00135`) inside `texturas`; if it exists, the game reads only that one.

With the game text set to Brazilian Portuguese, the document screens use the port's own translated images.

**Not covered:** about 9% of the textures have no close match; 162 textures that mix foreign (mostly Russian) text were left out; online leaderboard, windows, credits and manual screens were left out. 46 textures (doors, plants, title screen and typewriter background) that no pack covered were enlarged or redrawn with AI tools and adjusted for the port.

## Português

As texturas são trabalho de outras pessoas da comunidade de Resident Evil. As imagens foram feitas originalmente para a versão de PCSX2 (PS2) do jogo. Para este port elas foram ligadas, imagem por imagem, às texturas do PS3 e salvas com os nomes de arquivo que o port espera (veja *Mods de textura* no README). A comparação, a correção de transparência e o empacotamento foram feitos por **Kastiel** (mantenedor do port).

**Vale para as três versões.** O jogo reconhece a textura pelo conteúdo, então um único conjunto de arquivos serve a todas:

| Versão | Texturas do pacote aproveitadas |
|---|---|
| Americana (NPUB30467) | 5.926 (todas) |
| Europeia (NPEB00553) | 5.908 (99,7%) |
| Japonesa (NPJB00135) | 5.759 (97%) |

O que uma versão não usa é ignorado, e a textura original do jogo continua. O pacote foi montado em cima da versão americana; na europeia e na japonesa só foi conferido que os nomes das texturas existem, **sem teste jogando**.

**Como usar**
1. Baixe e extraia o zip.
2. Launcher → **Mods** → **Pasta de texturas do mod**: escolha a pasta `texturas` (a que contém `comum`). Escolha **antes** de abrir o jogo.
3. Ligue **Substituir texturas** e jogue. **F9** liga e desliga o pacote durante o jogo.
4. Não crie dentro de `texturas` uma subpasta com o código da versão (`NPUB30467`, `NPEB00553`, `NPJB00135`); se ela existir, o jogo lê só ela.

Com o texto do jogo em português do Brasil, as telas de documento usam as imagens traduzidas do próprio port.

**Fora do pacote:** cerca de 9% das texturas não tiveram par parecido; 162 texturas com texto estrangeiro (principalmente russo) ficaram de fora; placar online, janelas, créditos e manual também. 46 texturas (portas, plantas, tela de titulo e fundo da maquina de escrever) que nenhum pacote cobria foram aumentadas ou refeitas com ferramentas de IA e ajustadas para o port.
