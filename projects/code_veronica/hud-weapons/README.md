# HUD-only equipment icons

Seventeen recreated grayscale illustrations used only by the optional combat HUD and quick-equipment overlay. Includes the lighter. These are not extracted 3D models or replacements for the original inventory/SRT atlas. Runtime falls back to the player-selected game atlas if an external HUD illustration is absent.

The illustrations were recreated with the built-in image generation tool from the project owner’s supplied references. They ship with this port under the repository license.
